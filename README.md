# 🤖 Google Gemini AI UI Clone

> **Pixel-perfect Google Gemini AI Chat Interface clone featuring Markdown rendering, code syntax highlighting, prompt suggestions, and light/dark theme switching.**

---

## ✨ Key Features

- 💬 **Interactive AI Chat Interface**
  - Smooth conversational chat UI mimicking Google Gemini.
  - Supports Markdown text formatting (`marked.js`) for rich text responses.

- 💻 **Syntax Highlighted Code Blocks**
  - Integrated `highlight.js` for clean syntax highlighting across multiple programming languages.

- 💡 **Quick Prompt Suggestion Cards**
  - Interactive prompt chips (*Homework tips*, *Out-of-office email*, *Language phrases*, *DIY building*) to trigger instant prompts.

- 🌓 **Dynamic Theme Toggler**
  - Seamless Light and Dark mode switching with smooth color transitions and persistent state.

- 🗑️ **Chat Controls**
  - Instant conversation clear button and auto-scroll typing indicator.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3
- **Libraries**:
  - `marked.js` (Markdown Parser)
  - `highlight.js` (Code Syntax Highlighter)
  - `Boxicons` (Vector Icons)

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Omkar4812x/Gemini-UI-Clone.git
   cd Gemini-UI-Clone
   ```

2. **Launch Application**:
   Simply open `index.html` in any modern web browser or serve via Live Server.
